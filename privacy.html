TimeTree Sync privacy policy

Last updated November 8, 2026.

What it accesses

TimeTree Sync reads events from the owner's TimeTree calendar and writes them to a Google Calendar that the tool itself created. It uses Google's "calendar.app.created" permission, so it cannot read or change any other calendar, email, contacts or files in the Google account.

Where data goes

All processing happens on the owner's own computer. Calendar data goes only from TimeTree to the owner's Google Calendar. Nothing is sent to any other server, sold, shared or used for advertising.

What is stored

The TimeTree password is kept in Windows Credential Manager on that computer. The Google sign-in token and a small settings file are kept in the user's local app data folder. Running the included uninstall script deletes all of them.

Revoking access

Google access can be removed at any time from the Google Account's "Third-party apps and services" page.
